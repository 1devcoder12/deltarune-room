# Deltarune 全房间查询库
Deltarune Room‑ID Gallery，全章节房间场景浏览查询工具。

## 在线访问
- Cloudflare Pages（国内推荐）：shturl.cc/HkE0PtogcQrgK3rRN
- GitHub Pages（备份）：https://1devcoder12.github.io/deltarune‑room/

## 功能
- ✅ 第一章～第五章全部房间场景预览
- ✅ 支持搜索房间名、原生ID、数组ID
- ✅ 按章节快速切换浏览房间
- ✅ 显示房间原生ID、数组ID信息

> 提示：部分房间显示纯黑画面，为游戏原生测试占位房间，并非程序BUG。

## 部署说明
本项目为纯静态HTML，无需编译。
1. Cloudflare Pages 连接本仓库，构建命令留空，输出目录填写 `.`
2. 推送代码到 `main` 分支将自动重新部署。
